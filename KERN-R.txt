KERN-R Studio 3.3 — โปรแกรมตัดต่อวิดีโอ AI ครบวงจร

1. ระบบสถาปัตยกรรมและความปลอดภัย (Core & Security)
🗄️ คลังสื่อเก็บในเครื่องผู้ใช้ (Local Storage & IndexedDB)
จัดเก็บไฟล์ใน IndexedDB ของเบราว์เซอร์แยกรายบัญชี ข้อมูลปลอดภัยไม่หายแม้ปิดหน้าเว็บหรือรีเฟรช
💾 บันทึกโครงงานอัตโนมัติ (Auto-save System)
บันทึกสถานะไทม์ไลน์ แทร็ก และ Playhead ลง LocalStorage อัตโนมัติทุกความเปลี่ยนแปลงป้องกันงานหาย
🔄 ย้อนกลับและทำซ้ำ (Undo / Redo 50 Steps)
ระบบสลับย้อนกลับและทำซ้ำการแก้ไขบนไทม์ไลน์ได้สูงสุด 50 ขั้นตอน โดยไม่หน่วงหน่วยความจำ
🔒 ข้อมูลแยกขาดความปลอดภัยสูง (Multi-user Supabase RLS)
ควบคุมข้อมูลโปรเจกต์ด้วยนโยบาย RLS ของ Supabase บัญชีอื่นไม่มีสิทธิ์เข้าถึงหรือมองเห็นโครงการของคุณ
🌐 โดเมนหลักและระบบเชื่อมต่อเสถียร (Custom Domain & API Safety)
รันบนโดเมนหลัก https://kerntemplate.online พร้อมติดตั้งระบบ URL Helper ป้องกันบั๊ก CORS 100%

2. ส่วนประสานงานและแถบควบคุมเวลา (Editor Interface & Pro Timeline)
🌑 ดีไซน์ธีมมืดเว้นระยะปลอดภัย (Dark Slate & Spacing Polish)
หน้าจอโทนมืดสวยงาม มีระยะห่างขอบจอที่สมดุล ป้องกันแผงควบคุมเบียดหรือล้นตกขอบจอ
🛠️ แถบเครื่องมือควบคุมการตัด (Timeline Toolbar)
แถบปุ่มลัดทรงแคปซูล ประกอบด้วยปุ่มตัดด่วน (Split), ลบ (Delete), เล่น/หยุด (Play/Pause) และตัวคุมซูมไทม์ไลน์
🎞️ แทร็กตัดต่อแยกเลเยอร์เฉพาะ (Pro Timeline Tracks)
แยกแถวไทม์ไลน์ออกเป็น แทร็กภาพวิดีโอ, แทร็กเสียง และแทร็กตัวหนังสือ พร้อมปุ่มล็อกและปิดเสียงแยกแทร็ก
✂️ หั่นตัดและดึงปรับความยาว (Precision Split & Trim)
ใช้เมาส์ดึงขอบเพื่อปรับความยาว หรือกดคีย์ S บนคีย์บอร์ดเพื่อตัดแยกคลิปตรงตำแหน่ง Playhead ได้ทันที
🧲 แม่เหล็กดูดขอบและลากวางอิสระ (Visual Snapping & Free-form Drag)
ดูดคลิปให้แนบชิดติดขอบคลิปอื่นหรือพิกัด Playhead อัตโนมัติ ป้องกันหน้าจอดำระหว่างรอยต่อคลิป
🔍 ขยายมุมมองแกนเวลา (Timeline Zoom Slider)
ปรับยืดหดไทม์ไลน์ได้ตั้งแต่ 15% ถึง 400% เพื่อการตัดต่อเก็บงานละเอียดระดับเฟรมย่อย
🔉 แยกคลื่นเสียงจากคลิปวิดีโอ (Separate Audio)
คลิกขวาที่วิดีโอเพื่อแยกเสียงลงเลน Audio แยกต่างหากอัตโนมัติ พร้อมหรี่เสียงวิดีโอต้นฉบับเงียบสนิททันที

3. คลังสื่ออเนกประสงค์หน้าเดียวจบ (Unified Media Library)
📦 หน้ารวมอัปโหลดและนำเข้าลิงก์ (Single Unified Screen)
วางกล่องลากไฟล์อัปโหลดจากคอมพิวเตอร์และช่องกรอกนำเข้า URL จากเว็บไว้ในหน้าเดียวกัน ไม่ต้องคลิกสลับแท็บ
🎥 ตัวโหลดคลิปภายนอกอัจฉริยะ (YouTube & Web Downloader)
ดึงคลิปจากลิงก์ YouTube/TikTok เข้ามาตัด โดยหลังบ้านจะดาวน์โหลดเป็น Proxy 480p น้ำหนักเบาเพื่อให้สครับเล่นไม่กระตุก
🗑️ ปุ่มล้างแคชขยะคลังสื่อ (Clean Garbage)
ปุ่มล้างไฟล์ Blob ตกค้างใน IndexedDB และไฟล์ชั่วคราวหลังบ้าน เพื่อเพิ่มพื้นที่และประหยัดพื้นที่จัดเก็บ

4. แผงควบคุมและพรีวิวจอภาพ (Inspector & Canvas)
📐 ปรับแต่งขนาดหมุนภาพตรงแคนวาส (Direct Preview Transform)
กรอบสีขาว 8 จุดล้อมรอบชิ้นงานบนจอพรีวิว สามารถใช้เมาส์ยืดขยาย ย่อขนาด หรือคลิกหมุนเอียงชิ้นงานได้โดยตรง
🎨 ตกแต่งตัวหนังสือภาษาไทยพรีเมียม (Text Styling & Custom Fonts)
Inspector ตัวอักษรรองรับฟอนต์ไทยยอดนิยม ปรับขนาด สี ปรับแต่งเส้นขอบตัวพิมพ์ และสีพื้นหลังกล่องข้อความได้อิสระ
🎚️ สไลเดอร์ระดับสีวิดีโอ (Color EQ Adjustments)
ปรับระดับความสว่าง (Brightness), คอนทราสต์ (Contrast) และความสดสี (Saturation) แยกคลิปได้แบบเรียลไทม์
🎭 จางภาพและเสียงเข้าออก (Transition Fades)
ปรับตั้งเวลาเลือนหายตอนเริ่มคลิป (Fade In) และตอนท้ายคลิป (Fade Out) ช่วยให้ชิ้นงานต่อเนื่องอย่างกลมกลืน

5. ระบบปัญญาประดิษฐ์และประมวลผล (AI & Processing Engines)
🎙️ เปลี่ยนข้อความเป็นเสียงพากย์ AI (Intelligent AI Voiceover)
แปลงบทพิมพ์เป็นเสียงพูดธรรมชาติทันทีผ่าน Edge TTS th-TH-NiwatNeural และมีระบบสำรอง Google TTS Fallback มั่นใจสำเร็จ 100%
🔤 ทำคำบรรยายพรีเมียมอัตโนมัติ (ASS Subtitles Engine)
แปลงข้อความบรรยายบนไทม์ไลน์เป็นซับไตเติล ASS พร้อมใส่แอนิเมชันเครื่องพิมพ์ดีดและเฟดเข้าออกแบบสวยหรู
🔊 ปรับแต่งและผสมเสียงระดับเดซิเบล (Intelligent Audio Mixer)
รวมคลื่นเสียงทั้งหมด แปลงระดับเสียงสไลเดอร์ dB เป็น Linear และ resampling เป็น Stereo 44.1kHz เท่ากันทั้งหมดเพื่อความสมบูรณ์แบบ

6. คิวเรนเดอร์หลังบ้านประสิทธิภาพสูง (Cloud Server-Side Rendering)
🎥 เรนเดอร์วิดีโอคลาวด์เสถียร (Cloud Timeline Processor)
ส่งงานเข้าคิวเรนเดอร์คลาวด์หลังบ้าน โดยระบบจะดึงไฟล์ดิบอย่างรวดเร็วและใช้ FFmpeg compile วิดีโอสเกล 'contain' 1080p ลบลายน้ำภายนอก
🖥️ เร่งความเร็วการเรนเดอร์และ Fallback (Hardware Acceleration)
เร่งเข้ารหัสความเร็วสูงด้วยชิป GPU (NVENC/Media Foundation) และสลับกลับไปใช้ CPU (libx264) อัตโนมัติทันทีหากเกิดปัญหา เพื่อให้งานส่งออกสำเร็จ 100%
🏥 ตรวจสุขภาพ API หลังบ้าน (Real-time Health Checker)
ไอคอนแสดงสถานะไฟสัญญาณเตือนการเชื่อมต่อกับ Render Server (ไฟเขียว = ออนไลน์เสถียร / ไฟแดง = ออฟไลน์) ก่อนกดเรนเดอร์

7. ระบบตั้งเวลาและตรวจคุณภาพ (Automation & Keep-Alive)
🚀 ตรวจสอบบิลด์ก่อนขึ้นระบบจริง (GitHub Actions CI)
ป้องกันโค้ดหรือบิลด์เสียหายขึ้นระบบจริงด้วยการตรวจสอบบิลด์ NestJS และ Next.js 16 แยกจากกันผ่าน GitHub Actions
⏰ ปลุกเซิร์ฟเวอร์เรนเดอร์ไม่ให้สลบ (Multi-Option Keep-Alive)
รัน Cron Job เคาะกระตุ้นสุขภาพ Render Server ทุกๆ 15 นาที เพื่อแก้ปัญหา Cold Start ของเซิร์ฟเวอร์ Railway ทำให้ระบบตอบสนองเร็วทันที
