KERN-R Studio — สุดยอดโปรแกรมตัดต่อวิดีโอ AI ครบวงจร

ความสามารถปัจจุบัน (V3.0 - CapCut Clone Engine):

1. ระบบ Core Architecture ใหม่:
- 🗄️ Local Database (IndexedDB): บันทึก Media Files ลง Browser ป้องกันไฟล์หายเมื่อ Refresh
- 💾 Auto-save System: บันทึก Timeline State ลง LocalStorage อัตโนมัติทุกการเคลื่อนไหว
- 🔄 History Engine: ระบบ Undo/Redo สูงสุด 50 ขั้นตอน สำหรับทุก Action (ปุ่มใน TopBar ทำงานได้จริง)

2. ระบบ Advanced Timeline Engine (V3):
- 🧲 Magnetic Timeline: ระบบแทร็กหลักที่คลิปดูดติดกันอัตโนมัติ (CapCut Style)
- ✂️ Multi-Track Precision: รองรับแทร็ก Video (Main/PIP), Audio, Text และ Overlay แยกกัน
- 📏 Precision Editing: ตัดคลิป (Split), ยืด/หด (Trim) และเคลื่อนย้ายคลิปได้ลื่นไหล
- 🧩 Snapping Logic: ระบบดูดติดขอบคลิปและ Playhead เพื่อความแม่นยำ

3. ระบบ Canvas & Inspector (Phase 3 — ใหม่):
- 🎬 Video Transform: ปรับ Scale X/Y, Position X/Y, Opacity, Rotate ได้จาก Inspector panel
- 🖼️ Canvas Transform: วิดีโอแสดงผล transform (scale/position/rotate/opacity) บนหน้าจอพรีวิวจริง
- 📝 Text Styling ขั้นสูง: ปรับ Stroke (ขอบ), Background color, Font Family ได้อย่างอิสระ ไม่มีเงาที่จำกัดสี
- 🔲 Text Resize Handles: ลากปรับขนาด Text Overlay โดยตรงบน Canvas พร้อมกรอบสีขาวและ Rotate handle แบบ CapCut
- 🧩 Inspector Component: แผง Properties แบบแยก Tab สไตล์ CapCut Online, สามารถปรับความดังเสียงในหน่วย เดซิเบล (dB) ได้อย่างละเอียด
- 🖱️ Timeline Navigation: รองรับการเลื่อน Timeline แนวนอนด้วยลูกกลิ้งเมาส์ (Mouse Wheel)
- ✂️ Separate Audio: คลิกขวาที่คลิปเพื่อแยกเสียงออกจากภาพ (ปิดเสียงคลิปเดิมและสร้าง Track เสียงใหม่ให้อัตโนมัติ)
- 🖼️ Video Thumbnails: คลิปบนไทม์ไลน์แสดงรูป Thumbnail เป็นพื้นหลังให้รู้ว่าคลิปไหนเป็นคลิปไหน
- ⚡ Audio Sync Engine: ระบบเช็คการโหลดข้อมูล (Buffering check) ป้องกันปัญหาเสียงเล่นไปก่อนที่วิดีโอจะโหลดเสร็จ

4. สถาปัตยกรรม (อัปเดตล่าสุด):
- ลบระบบ Electron ออกทั้งหมด เปลี่ยนเป็น Web-Native แบบเต็มตัวเพื่อความรวดเร็วและใช้ขุมพลังเบราว์เซอร์
- ระบบสร้าง Track อัตโนมัติ (Dynamic Tracks) ไม่ต้องจอง Track ล่วงหน้า

4. ระบบ AI Voice & Subtitles Pro:
- 🎙️ AI Voiceover (New): รวมระบบ Edge TTS เข้ากับหน้าตัดต่อโดยตรง เลือกเสียงไทย/อังกฤษ และสร้างคลิปลงไทม์ไลน์ได้ทันที
- 🗣️ Audio Engine: ระบบแยกเสียง (Separate Audio) ที่แม่นยำ พร้อมการควบคุมระดับเสียงแยกรายคลิป
- ⚙️ Multi-Engine Support: รองรับ edge-tts, Kokoro TTS และ Piper TTS

5. ระบบประมวลผลวิดีโอระดับโปร (Cloud Rendering):
- ☁️ Backend Export Engine: เปลี่ยนจากการเรนเดอร์บนเบราว์เซอร์ มาเป็นการส่งงานไปเรนเดอร์บน Server (Node.js + FFmpeg)
- 🎞️ Multi-Layer Render: รองรับการ Overlay วิดีโอ/รูปภาพ, ผสมเสียง และฝังซับไตเติ้ล (Burn-in Text) แบบสมบูรณ์
- 📊 Progress Tracking: ระบบ Polling เช็คสถานะการเรนเดอร์แบบ Real-time พร้อมดาวน์โหลดอัตโนมัติเมื่อเสร็จ
- 📦 Supabase Integration: บันทึกวิดีโอที่เรนเดอร์เสร็จแล้วลงบน Cloud Storage (Bucket: assets) ถาวร
